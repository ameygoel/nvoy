Partner programme logos. Save each logo as <programme id>.svg or .png (ids are in programs.json, e.g. marriott-stars.svg, hyatt-prive.png)
and set "logo": "assets/img/programs/<file>" on that programme. Use the official marks from the programme's partner portal; transparent background, roughly 3:1, at least 600px wide.
Until a logo is present the site shows the programme name as a typeset tile.
